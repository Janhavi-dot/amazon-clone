**Amazon Clone**

A responsive Amazon Clone website created using HTML and CSS.



**Project Overview:**

This project is a frontend clone of the Amazon website created to practice web development concepts.



**Technologies Used:**

\- HTML5

\- CSS3



**Features:**

\- Amazon-style navigation bar

\- Search bar

\- Product categories

\- Product cards

\- Promotional sections

\- Footer

\- Hover effects

\- Responsive layout
